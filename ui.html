Scale UI

New Scale Column

Ghost column rendered at the end of the scales container. Dashed neutral outline, centered plus icon + label. Replaces the old header button. Click → adds a scale and scrolls it into view.

.new-scale-column > svg + .new-scale-label

Scroll Arrows

Full-height edge-anchored nav, always visible (hidden via [hidden] only at scroll extremes). Solid tinted glass: backdrop-filter: blur(12px) over color-mix(in srgb, var(--bg) 75%, transparent). Resting width 32px — exactly fills the container's 32px inline padding, which matches the header gutter so the first column aligns with the page title. Grows smoothly to 64px on hover, overlaying the blurred column edge.

.scroll-arrow (.scroll-arrow-left / .scroll-arrow-right) — inset-block: 0, inline-size: 32px → 64px on hover, transition: inline-size 0.2s ease-out

Swatch Rows

One row per step in manager.stepLabels (default 35). Major steps (label divisible by manager.majorDivisor, default 50) are taller; minor steps are compact. Full-width color blocks with hover overlay.

450L0.58 C0.010 H67
.swatch-row .minor .swatch-overlay (visible on hover)
Indicator dots: .gamut-dot (amber, gamut-clamped) · .adjusted-dot (blue, L-adjusted)

Hovering a swatch adds WCAG tier classes and ratio badges to all other rows. Vertical pills appear in the column gap.
