9. Contrast Hover System

When hovering any swatch row, all other rows receive a WCAG tier class and a contrast ratio badge. The hovered row gets .hover-source.

TierGapRow ClassToken FamilyBadge (Light)Bar

AA (4.5:1)≥ 500 .contrast-aa --info (Violet) --info-subtle / --info-fg --info
A (3:1)≥ 400 .contrast-a --warning (Yellow) --warning-subtle / --warning-fg --warning
None< 400 .contrast-none (neutral tokens) --bg-muted / --text-muted (none)

19. Semantic Color Families — Scale Derivation

All semantic accent colors are sourced from the default scales' generated steps. Each family maps to a specific scale, using step 400-500 for the main accent, step 50 for subtle backgrounds, and step 800 for text-on-subtle.

FamilySource ScaleMain (step)Subtle (step)Foreground (step)UI Role
Warning Yellow 300 50 800 A-tier contrast, gamut dot, out-of-range
Info Violet 500 50 800 AA-tier contrast
Positive Aqua 400 50 800 AAA-tier contrast
Danger Red 450 50 800 Delete, fail, error toast
Success Green 400 50 800 Pass indicators
Adjusted Blue 400 50 800 L-adjusted steps, Figma API info

Previously these were hardcoded Tailwind-palette hex values. Now they are all CSS custom properties registered via @property, using colors generated by ChromaScale's own OKLCH engine from the default scale inputs.
