Scale UI

Swatch Rows

35 per column. Major steps (multiples of 50) are taller; minor steps are compact. Full-width color blocks with hover overlay.

450L0.58 C0.010 H67
.swatch-row .minor .swatch-overlay (visible on hover)
Indicator dots: .gamut-dot (amber, gamut-clamped) · .adjusted-dot (blue, L-adjusted)

Contrast Hover

Hovering a swatch adds WCAG tier classes and ratio badges to all other rows. Vertical pills appear in the column gap.

TierGapClassPill Color
AAA (7:1)≥ 600.contrast-aaa--positive
AA (4.5:1)≥ 500.contrast-aa--info
A (3:1)≥ 400.contrast-a--warning
None< 400.contrast-none— (row opacity 0.5)

.contrast-ratio-badge

+400 · 3.2:1 +500 · 5.1:1 +600 · 8.2:1
Format: +{gap} · {ratio}:1. Colors set inline from scale palette (700-step text, 100-step bg, flips at 500).
